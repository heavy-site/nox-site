# media

Фото залу. Кладіть файли сюди — сайт підхопить їх сам, правити код не треба.

- Формати: `.jpg` `.jpeg` `.png` `.webp` `.avif`
- Порядок — за іменем файлу: `01-zal.jpg`, `02-bar.jpg`, `03-terasa.jpg`
- Підпис: покладіть поруч текстовий файл із тим самим іменем — `01-zal.txt`
- Поки папка порожня, на місці галереї показується креслення залу

Стискайте перед завантаженням: 1600–2400 px по довгій стороні, до ~400 КБ.
